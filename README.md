# Мой день

Личный планер-дневник: главные дела дня, цели, самочувствие, заметки, планы на выходные, календарь настроения, график за 14 дней, итоги недели и настраиваемые напоминания со своим звуком.

## Файлы

| Файл | Что это |
|---|---|
| `moy-den.html` | Приложение целиком: одна HTML-страница со стилями, скриптом и встроенным звуком уведомления |
| `PRD_Moy_den_planer.md` | Описание продукта (PRD), версия 1.2 |
| `WhatsApp Audio 2026-11-02 at 13.58.11.mpeg` | Исходный звук уведомления |

## Как открыть

Основная версия опубликована как личная страница в Claude. Там записи сохраняются в облаке и одинаковы на всех устройствах.

Файл `moy-den.html` можно открыть и просто в браузере. Тогда записи хранятся только в этом браузере.

## Возможности

- 5–6 главных дел с отметкой выполнения, ★ для важных и переносом невыполненных на завтра
- Дневник: настроение, энергия, сон, самочувствие тела, заметки
- Календарь месяца, окрашенный по настроению
- График настроения, энергии или сна за 14 дней
- Итоги недели
- Напоминания по времени и дням недели со звуковым сигналом
- 5 цветовых тем и тёмный режим
